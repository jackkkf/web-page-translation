# 产品需求文档：轻译 LiteTrans

## 1. 一句话定位

一个开源、免费、默认不索取网页权限的浏览器双语对照翻译扩展。

## 2. 目标用户与场景

| 用户          | 场景                               | 最在意的                     |
| ------------- | ---------------------------------- | ---------------------------- |
| 技术人员      | 读英文文档、GitHub issue、技术博客 | 原文可核对、代码块不能被翻译 |
| 学生 / 研究者 | 读外文资料与论文网页               | 译文质量、双语对照           |
| 隐私敏感用户  | 日常浏览                           | 权限要求最小、代码可自查     |
| 中国大陆用户  | 无代理环境下阅读外文网页           | 默认引擎能直连               |

## 3. 首期（v0.1）功能范围

### 3.1 必须有

| 编号 | 功能         | 验收标准                                                                     |
| ---- | ------------ | ---------------------------------------------------------------------------- |
| F-01 | 整页双语翻译 | 点击图标 →「翻译此页面」，译文插在每段原文下方，原文保持可读                 |
| F-02 | 还原原文     | 再次点击或按 Alt+A，所有插入的译文节点被清除，页面与翻译前完全一致           |
| F-03 | 引擎切换     | popup 下拉可切换必应 / 谷歌 / 百度，切换后「重新翻译」立即生效               |
| F-04 | 引擎降级     | 主引擎失败时自动用降级引擎重试；连续失败 3 次后熔断 60 秒，期间直接走降级    |
| F-05 | 语言设置     | 可设源语言（含自动检测）与目标语言，覆盖 26 种语言                           |
| F-06 | 视口内懒翻译 | 长页面首屏只翻译可见区域及前后 600px，滚动时增量翻译                         |
| F-07 | 动态内容跟进 | SPA 路由切换、无限滚动新增的内容会被自动翻译                                 |
| F-08 | 译文样式     | 5 种样式（虚线/实线下划线、高亮、卡片、无标记）+ 两种展示模式（对照/仅译文） |
| F-09 | 站点规则     | 按域名设「始终翻译 / 从不翻译」，支持 `*.` 泛域名，更精确的规则优先          |
| F-10 | 翻译缓存     | 相同引擎+语言方向+原文命中缓存不再请求；可查看统计与清空                     |
| F-11 | 最小权限     | 安装时不出现「读取所有网站数据」提示；manifest 无 `content_scripts`          |
| F-12 | 百度密钥配置 | 选项页可填 APPID/密钥，只存 `storage.local`，密钥输入框为 password 类型      |
| F-13 | 错误可见     | 翻译失败时在段落原位显示可读原因（如「引擎鉴权失败，请检查密钥配置」）       |
| F-14 | 跨浏览器     | Chrome / Edge / Firefox 三份产物均可正常安装运行                             |

### 3.2 不翻译的内容（明确排除）

- `<script>` `<style>` `<pre>` `<code>` `<kbd>` `<textarea>` `<input>` 等标签内文本
- 带 `translate="no"`、`.notranslate`、`aria-hidden="true"`、`contenteditable` 的元素及其子树
- 纯数字、纯标点、纯符号的片段
- 已经是目标语言的段落（CJK 目标语言下按字符集启发式判断）
- 扩展自己插入的译文节点（防止二次翻译）

### 3.3 明确不做（首期）

PDF 翻译、EPUB、视频字幕、划词翻译、悬停翻译、输入框翻译、AI 大模型引擎、账号系统、云同步、术语库。

## 4. 非功能需求

| 维度   | 要求                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 性能   | 首屏翻译请求数与页面总长度无关，只与可见区域段落数有关                    |
| 性能   | 内容脚本产物 < 50 KB，background < 60 KB                                  |
| 隐私   | 不自建任何服务器；页面内容只发往用户所选的翻译服务；不采集任何遥测        |
| 可靠性 | 任何引擎错误都不得导致页面白屏或原文丢失；还原必须能完全恢复原始 DOM 文本 |
| 兼容性 | Chrome / Edge 最近两个稳定版；Firefox 115 ESR 及以上                      |
| 可维护 | 新增一个翻译引擎只需改 4 个文件，不触碰 UI、缓存、限流、降级逻辑          |

## 5. 交互设计

### popup（点击图标）

```
┌──────────────────────────────┐
│ 轻译                    设置 │
│ ┌──────────────────────────┐ │
│ │      翻译此页面          │ │  ← 已翻译时变为「显示原文」
│ └──────────────────────────┘ │
│ 翻译中… 12/48 段             │  ← 仅翻译进行中显示
│ 翻译引擎 [微软翻译（免费）▾] │
│ 原文语言 [自动检测▾] 译文 [简体中文▾] │
│ 展示方式 [双语对照▾] 样式 [虚线▾]     │
│ 切换设置后点「重新翻译」生效  重新翻译 │
└──────────────────────────────┘
```

设计原则：**主操作只有一个按钮**，其余是二级设置；进度可见，失败原因可见。

### 选项页（独立标签页）

分组：翻译引擎 → 百度密钥 → 自动翻译与站点规则 → 默认语言 → 翻译缓存。
第一屏第一句话就是隐私声明。
