# 路线图

## v0.1 —— 骨架与核心链路（当前状态）

已完成：

- WXT + React + TS 工程骨架，一条命令产出 Chrome / Edge / Firefox 三份产物
- 引擎适配层：微软（默认）、谷歌（降级）、百度（需密钥）
- 编排层：缓存 → 分批 → 限流 → 重试 → 降级 → 熔断
- 内容脚本：段落收集、双语注入与还原、视口内懒翻译、动态内容跟进
- popup 与选项页
- 最小权限模型（无 `content_scripts`、无 `<all_urls>`）
- 68 个单测覆盖引擎、编排、DOM 遍历、渲染、限流、站点规则

进入 v0.2 之前必须补齐：

- [ ] 品牌图标（目前是 WXT 脚手架的默认图标）
- [ ] 在 10 个代表性站点上人工验收（见 `docs/testing/manual-checklist.md`）
- [ ] 隐私政策页面（商店提交必填）
- [ ] 商店素材：截图、宣传图、各语言文案

## v0.2 —— 覆盖度与交互补全

目标：把"能翻译"变成"什么都能翻译"。

| 项              | 说明                                                       |
| --------------- | ---------------------------------------------------------- |
| 划词翻译        | 选中文本后浮层显示译文，是使用频率最高的补充场景           |
| 悬停翻译        | 鼠标停在段落上按修饰键即翻单段                             |
| iframe 内容     | `allFrames: true` 注入，注意同源与嵌套层级                 |
| Shadow DOM 穿透 | 递归遍历 open shadow root                                  |
| 属性文本        | `title` / `alt` / `placeholder` / `aria-label`             |
| 界面多语言      | 接入 `@wxt-dev/i18n`，先做中/英                            |
| 站点适配规则    | 参考 KISS Translator：按 URL + CSS 选择器指定翻译/忽略范围 |
| 浮动球          | 页面内快捷入口，避免每次都点工具栏                         |

## v0.3 —— 引擎生态与专业能力

| 项              | 说明                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| 自定义 API 引擎 | 用户填 endpoint + 请求/解析模板，支持 OpenAI 兼容接口、LibreTranslate 等 |
| AI 引擎         | OpenAI / Gemini / DeepSeek 等，用户自备 Key                              |
| 术语库          | 指定术语的固定译法，AI 引擎与传统引擎都生效                              |
| DeepL           | 用户自备 Key 的官方 API                                                  |
| 富文本翻译      | 保留行内标签（链接、加粗）的结构，而不是纯文本进出                       |
| 设置导入导出    | JSON 导出，方便迁移与备份（密钥可选择不导出）                            |

## 明确不做

| 项                | 原因                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| PDF / EPUB 翻译   | 沉浸式翻译的护城河，需要排版引擎级投入，投入产出比不成立             |
| 视频字幕翻译      | 需逐平台适配且极易被平台改动打破                                     |
| 自建翻译中转服务  | 一旦经过我们的服务器，隐私叙事和合规责任全变；服务器还会成为封禁单点 |
| 账号系统 / 云同步 | 与"不收集任何数据"的定位冲突；需要同步的用户可用设置导出             |
| 任何形式的遥测    | 同上。问题反馈走 GitHub Issue                                        |
