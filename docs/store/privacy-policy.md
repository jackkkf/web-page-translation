# 隐私政策

最后更新：2026-09-05

## 简短版

轻译不收集、不存储、不传输你的任何个人数据。我们没有服务器。

## 我们不做什么

- 不运营任何服务器，因此不可能收集你的数据
- 不收集浏览历史、页面内容、个人信息
- 不使用任何统计、埋点、遥测、崩溃上报服务
- 不使用 Cookie 或任何跨站追踪技术
- 不出售、不共享、不转移任何数据给第三方

## 数据如何流动

当你**主动**点击扩展图标、使用快捷键或右键菜单触发翻译时：

1. 扩展读取当前页面的可见文本
2. 这些文本被直接发送给**你所选择的翻译服务**（必应、谷歌或百度）
3. 译文返回后显示在页面上，并可选缓存在你的本机

文本直接从你的浏览器发往翻译服务，不经过我们的任何设施。

未触发翻译时，扩展不在任何网页上运行，也不读取任何内容。

## 第三方翻译服务

你所选引擎会收到待翻译的文本。这些服务有各自的隐私政策，请自行查阅：

- 必应翻译（微软）：https://privacy.microsoft.com/privacystatement
- 谷歌翻译：https://policies.google.com/privacy
- 百度翻译：https://www.baidu.com/duty/

**建议**：不要翻译含有密码、身份证号、银行卡号等敏感信息的页面。

## 本机存储的数据

以下数据只保存在你的浏览器本机（`storage.local`），从不上传：

| 数据     | 用途                           |
| -------- | ------------------------------ |
| 偏好设置 | 引擎、语言、译文样式、站点规则 |
| 翻译缓存 | 避免重复请求，可在选项页清空   |
| 百度密钥 | 调用百度翻译 API（若你填写了） |

密钥刻意保存在 `storage.local` 而非 `storage.sync`，因此不会同步到你的浏览器账号或云端。

卸载扩展会删除全部本机数据。

## 权限说明

见 `docs/decisions/0002-permission-model.md`。扩展默认不申请任何网站的访问权限；仅当你主动开启「自动翻译」时才会请求，关闭时会主动撤回。
