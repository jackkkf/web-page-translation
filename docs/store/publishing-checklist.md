# 上架清单

三个商店的规则不同，按顺序走：**Chrome → Edge（复用 Chrome 包）→ Firefox**。

## 0. 提交前自检（三商店通用）

```bash
npm run verify        # format + lint + compile + test + build:all + check:manifest
npm run test:live     # 确认三个翻译接口现在都还活着（免费端点会不打招呼地下线）
npm run zip:all       # 产出三份可提交的 zip
```

- [ ] `manifest.json` 里的每个权限都在代码中真实使用（多余权限在任何商店都算缺陷）
- [ ] 没有远程代码执行：无 `eval`、无 `new Function`、无远程 `<script>`、无远程加载的 JS 字符串
- [ ] 所有依赖已打包进产物，运行时不从网络拉取任何逻辑
- [ ] 产物未混淆（压缩可以，混淆会导致审查员无法验证行为）
- [ ] 图标齐全：16/32/48/96/128
- [ ] 版本号已递增，`CHANGELOG.md` 已更新
- [ ] 隐私政策页面已上线且可公开访问

### 关于「远程代码」的自查要点

我们向翻译接口发的是**数据**（待译文本），收到的也是**数据**（译文），不是逻辑。这符合 Chrome MV3 的要求（政策允许"与远程服务器通信"，禁止"从远程执行逻辑"）。填写审查表时如实选择「不使用远程代码」。

## 1. Chrome Web Store

注册开发者账号需一次性 5 美元。

### 商店信息

- **名称**：轻译 LiteTrans - 网页双语对照翻译（≤ 75 字符）
- **简短说明**（≤ 132 字符）：免费开源的网页双语对照翻译扩展。支持必应/谷歌/百度多引擎切换，默认不索取任何网站访问权限。
- **类别**：工具（Tools）
- **截图**：1280×800 或 640×400，至少 1 张，建议 5 张
  1. 英文技术文档的双语对照效果
  2. popup 界面（引擎切换）
  3. 选项页（隐私声明 + 引擎配置）
  4. 站点规则
  5. 安装时的权限提示对比（我们没有"读取所有网站数据"）
- **宣传图块**：440×280（小）、920×680（大）、1400×560（Marquee）

### 隐私实践页（逐项照抄）

| 字段                | 填写内容                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| 单一用途说明        | 将用户当前浏览的网页文本翻译成用户指定的语言，并以双语对照方式展示。                               |
| `activeTab` 理由    | 见 `docs/decisions/0002-permission-model.md`「商店权限说明」                                       |
| `scripting` 理由    | 同上                                                                                               |
| `storage` 理由      | 同上                                                                                               |
| `contextMenus` 理由 | 同上                                                                                               |
| host 权限理由       | 同上（4 个翻译服务域名）                                                                           |
| 是否使用远程代码    | **否**                                                                                             |
| 数据用途声明        | 不收集也不传输任何用户数据到我们的服务器。待翻译文本仅发送给用户所选的第三方翻译服务用于生成译文。 |

- [ ] 勾选：不出售或转移数据给第三方
- [ ] 勾选：不将数据用于与核心功能无关的用途
- [ ] 勾选：不将数据用于判定信用或放贷

### 审查预期

因为**没有**广泛 host 权限，预计数天内通过。若被要求补充说明，重点强调：`content_scripts` 为空、host 权限只含 4 个接口域名、全部代码开源可核对。

## 2. Microsoft Edge Add-ons

- 免费注册，可直接复用 Chrome 的 MV3 zip（也可用 `npm run zip:edge`）
- 商店文案与截图可复用，尺寸要求略宽松
- 需单独填写权限说明，内容与 Chrome 一致
- 审查通常 1–7 个工作日

## 3. Firefox AMO

产物为 MV2（见 `docs/decisions/0003-firefox-manifest-version.md`）。

- [ ] `browser_specific_settings.gecko.id` 已改成正式的扩展 ID（当前是占位的 `litetrans@example.com`）
- [ ] 准备**源码包**：AMO 要求提交可复现构建的源码与构建说明
- [ ] 构建说明写明：Node 版本、`npm ci`、`npm run zip:firefox`
- [ ] 本地先跑 `npx web-ext lint --source-dir .output/firefox-mv2` 排掉常见问题

AMO 的特点：不要求逐权限填理由，但审查员会索要源码验证产物与仓库一致；所有扩展必须由 Mozilla 签名。
